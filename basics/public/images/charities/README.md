# Charity Logos

Place the following logo files in this directory:

- `nariz-vermelho-logo.png` — Nariz Vermelho
- `acreditar-logo.png` — Acreditar
- `make-a-wish-logo.png` — Make-A-Wish
- `unicef-logo.png` — UNICEF

Logos should be transparent PNGs optimized for web use.
They will be displayed at a maximum height of 48px.
